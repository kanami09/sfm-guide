# 实战项目

前六章逐个介绍了 SFML 的语法。本章把它们组合起来，完成几个完整的实际项目。每个项目都包括：

- **需求**：要解决什么问题；
- **布局与标签**：方块怎样摆，各贴什么标签；
- **程序**：完整代码；
- **讲解**：为什么这样写，有哪些坑，可以怎样变化。

| 项目 | 用到的主要特性 |
| --- | --- |
| [熔炉阵列](ch07-01-furnaces.md) | `TO EACH`、`RETAIN`、方向、`FORGET`、`WITH` |
| [仓库收纳与整理](ch07-02-storage.md) | 多个 `OUTPUT` 分流、通配符、`EMPTY SLOTS IN` |
| [机器补料：维持库存](ch07-03-stocking.md) | `RETAIN EACH`、`IF HAS`、集合运算符 |
| [流体、能量与化学品](ch07-04-fluids-energy.md) | 资源类型、每刻触发、Mekanism 面配置 |
| [AE2 压印器](ch07-05-ae2.md) | 槽位、`RETAIN`、多触发器协作、防死锁 |

<div class="note">

**提示**：示例中的标签名都是英文。如果你喜欢用中文标签，记得加引号，例如 `"熔炉"`。

</div>
