# 输入与输出

`INPUT` 和 `OUTPUT` 是 SFML 的核心。本章回答两个问题：**从哪里搬**、**搬到哪里**。至于**搬什么、搬多少**，留到第 5 章讲。

本章内容：

- [INPUT 与 OUTPUT 的工作模型](ch04-01-io-model.md)：为什么说“`INPUT` 什么都不做”，多条语句之间怎样配合；
- [标签](ch04-02-labels.md)：怎样指定一个或多个来源、目的地；
- [方向](ch04-03-sides.md)：访问方块的哪一个面，包括相对方向；
- [槽位](ch04-04-slots.md)：只访问指定编号的槽位；
- [EACH：逐个方块计数](ch04-05-each-label.md)：`FROM EACH` / `TO EACH`；
- [EMPTY SLOTS IN](ch04-06-empty-slots.md)：只放进空槽位；
- [FORGET](ch04-07-forget.md)：撤销已登记的来源；
- [ROUND ROBIN](ch04-08-round-robin.md)：在多个方块或标签之间轮流选择。

先给出两条语句的完整语法，后面各节会逐一拆开讲：

```text
INPUT  [资源限额列表] [EXCEPT 资源列表] FROM [EACH] 标签访问
OUTPUT [资源限额列表] [EXCEPT 资源列表] TO [EMPTY SLOTS IN] [EACH] 标签访问

标签访问 = 标签 {, 标签} [ROUND ROBIN BY (LABEL|BLOCK)] [方向限定 SIDE] [SLOTS 槽位列表]
```

方括号表示可选，花括号表示可以重复。**标签访问中各部分的顺序是固定的**：标签 → 轮询 → 方向 → 槽位。
