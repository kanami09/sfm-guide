# AE2 压印器

本节逐行分析模组内置示例 `ae2_inscribers.sfml`。它是官方示例中最复杂的一个，几乎用到了第 4、5 章的所有知识。

## 背景

在 Applied Energistics 2 中，制作处理器需要两步压印：

1. **印刷电路板**：在压印器中放入压印模板（逻辑、工程、计算、硅），配合对应的材料（金锭、钻石、赛特斯石英水晶、硅）压出“电路板”；
2. **组装处理器**：在没有模板的压印器中，上方放电路板，中间放红石，下方放硅板，压出处理器。

压印器的三个槽位，在 SFML 中的编号（参照示例中的用法）是：

| 编号 | 位置 | 用途 |
| --- | --- | --- |
| `SLOTS 0` | 上 | 模板，或者电路板 |
| `SLOTS 1` | 下 | 模板，或者硅板 |
| `SLOTS 2` | 中 | 材料 |

## 标签

| 标签 | 标记的方块 |
| --- | --- |
| `logic` | 装了逻辑压印模板的压印器 |
| `engineering` | 装了工程压印模板的压印器 |
| `calculation` | 装了计算压印模板的压印器 |
| `silicon` | 装了硅压印模板的压印器 |
| `last` | 用来组装处理器的压印器（不装模板） |
| `materials` | 材料箱 |
| `results` | 成品箱 |

注意，标签 `silicon` 和物品 `silicon`（硅）同名，但两者互不干扰：出现在 `FROM`/`TO` 后面的是标签，出现在资源条目里的是资源。

## 程序

```sfml
NAME "AE2 Inscribers"

-- labels:
-- logic, engineering, calculation, silicon, last => inscribers
-- materials, results => chests
EVERY 20 TICKS DO
    INPUT FROM materials

    OUTPUT RETAIN 2 gold_ingot TO EACH logic SLOTS 2
    OUTPUT RETAIN 2 diamond TO EACH engineering SLOTS 2
    OUTPUT RETAIN 2 certus_quartz_crystal TO EACH calculation SLOTS 2

    OUTPUT RETAIN 2 silicon TO EACH silicon SLOTS 2

    OUTPUT RETAIN 2 redstone TO EACH last SLOTS 2
    OUTPUT RETAIN 2 printed_silicon TO EACH last SLOTS 1

    OUTPUT
        RETAIN 2 printed_calculation_processor,
        RETAIN 2 printed_engineering_processor,
        RETAIN 2 printed_logic_processor
    TO EACH last SLOTS 0
FORGET
    INPUT FROM logic, engineering, calculation, silicon west side
    output to materials
FORGET
    INPUT FROM last west SIDE
    OUTPUT TO results
END
EVERY 200 TICKS DO
    IF SOME last HAS LT 3 THEN
        INPUT FROM last
        OUTPUT TO materials
    END
END
```

## 逐段讲解

### 第一段：分发材料

```sfml,ignore
INPUT FROM materials
OUTPUT RETAIN 2 gold_ingot TO EACH logic SLOTS 2
```

- `TO EACH logic`：**每台**逻辑压印器单独计数；
- `SLOTS 2`：只放进中间的材料槽；
- `RETAIN 2`：材料槽里最多保持 2 个。

示例的更新日志里提到，1.21.1 版 AE2 的压印器槽位可以堆叠多个物品，所以要用 `RETAIN` 限制数量。不然一台压印器会把材料箱里的金锭全部分走，其他压印器就分不到了。

后面几条同理，只是换了材料和目标标签。最后一条用三个逗号分隔的资源条目，分别给三种印刷电路板各自设置 `RETAIN 2`，统一放进 `last` 压印器的上方槽位。

### 第二段：回收印刷电路板

```sfml,ignore
FORGET
    INPUT FROM logic, engineering, calculation, silicon west side
    output to materials
```

- `FORGET` 撤销第一段的 `INPUT FROM materials`，否则这一段的 `OUTPUT` 会把材料箱的东西又搬回材料箱；
- 四种印刷压印器的产物都从**西面**取出（AE2 的压印器允许从任意侧面取出产物），送回材料箱。下一轮执行时，它们会作为材料分发给 `last` 压印器。

关键字大小写混用（`west side`、`output to`）完全合法，这也正好说明 SFML 的关键字不区分大小写。

### 第三段：收取处理器

```sfml,ignore
FORGET
    INPUT FROM last west SIDE
    OUTPUT TO results
```

组装好的处理器从 `last` 压印器的西面取出，放进成品箱。

### 第二个触发器：防止死锁

```sfml,ignore
EVERY 200 TICKS DO
    IF SOME last HAS LT 3 THEN
        INPUT FROM last
        OUTPUT TO materials
    END
END
```

这是示例中最巧妙的部分。设想有两台 `last` 压印器：A 拿到了印刷电路板和红石，但没拿到印刷硅；B 拿到了印刷硅，但没拿到电路板。两台都凑不齐材料，就会永远卡住。

解决办法是每 10 秒检查一次：只要有**任意一台**（`SOME`）`last` 压印器的物品总数少于 3 个（凑齐一次组装需要 3 个），就把**所有** `last` 压印器里的东西都退回材料箱，下一轮重新分发。

模组示例的注释特别提醒：这个触发器的间隔**必须比一次压印所需的时间长**，否则 SFM 可能会把正在加工、材料已经齐全的压印器里的东西也抽走，反而妨碍生产。
