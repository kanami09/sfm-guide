# 附录 E：版本差异与语言演进

## 本书覆盖的版本

本书以 SFM **4.34.0** 正式版为准。**4.35.0** 的更新内容（配方 ID 改用 `sfm:` 命名空间、法语本地化、一处搬运进度的修复）**不涉及 SFML 语言**，因此本书同样适用于 4.35.0。

4.34.0 支持以下 Minecraft 版本，它们的 SFML 语法**完全相同**：

> 1.19.2、1.19.4、1.20、1.20.1、1.20.2、1.20.3、1.20.4、1.21.0、1.21.1、26.1.2

## 不同 MC 版本之间的差异

语法相同，但下面这些与游戏环境有关的部分会因 MC 版本而异：

| 方面 | 差异 |
| --- | --- |
| **Mekanism 资源类型** | 1.19.2 ~ 1.20.3：`gas`、`infusion`、`pigment`、`slurry`、`mekanism_energy`<br>1.20.4、1.21.0：`gas`、`infusion`、`pigment`、`slurry`<br>1.21.1、26.1.2：`chemical`，`gas` 等是它的别名 |
| **通用物品标签（tag）的命名空间** | 较早的 Forge：`forge:`（如 `#forge:ingots`）<br>1.21 及以后的 NeoForge：`c:`（如 `#c:ingots`）<br>省略命名空间（`#ingots`）可以同时兼容 |
| **能力（Capability）系统** | NeoForge 在 1.20.3 前后重写了能力系统，SFM 内部做了适配，SFML 写法不受影响 |
| **JEI 支持** | 部分版本缺少 JEI 集成（见内置示例 “Known issues”） |
| **堆肥桶** | 1.20.3 及以后，不指定方向向堆肥桶输出时，会跳过“是否可堆肥”的检查，堆肥桶会变成垃圾桶（见内置示例 “Known issues”） |

## 语言特性演进

下表整理自模组内置的 `changelog.sfml`，只列出与 SFML 语言及其语义相关的条目。如果你在用较旧的整合包，可以对照此表判断某个特性能不能用。

| 版本 | 变化 |
| --- | --- |
| 4.12.0 | 数量/保留量后的 `EACH`；`EXCEPT` 资源排除 |
| 4.14.0 | `FORGET`；`ROUND ROBIN BY BLOCK/LABEL`；`redstone` 可以不加引号用作资源名 |
| 4.15.0 | 集合运算符中 `EACH` 作为 `EVERY` 的别名；`EACH SIDE`；`fe`/`rf`/`energy`/`power` 作为 `forge_energy` 的别名；只搬能量的触发器可以更快执行；最小间隔可配置 |
| 4.16.0 | `mekanism_energy` 资源类型；`EVERY TICK DO` 写法；`IF chest HAS EQ 0 THEN`（不写资源）；`redstone` 可以用作标签；修复输入端数量限制在多个输出间不生效的问题 |
| 4.17.0 | 修复部分 `FORGET` 重置计数器的问题；加入资源类型不匹配的警告 |
| 4.18.0 | 改进 `EXCEPT` 的性能 |
| 4.19.0 | `WITH TAG` 物品标签（tag）匹配；资源标识符自动转小写；1.21.1 上 `gas::` 等成为 `chemical::` 的别名 |
| 4.20.0 | 资源之间的 `OR`；修复 `WITH`/`WITHOUT` 的逻辑；`GLOBAL` 时钟和 `PLUS` 偏移量；`EACH` 性能优化；修复多个来源时 `RETAIN` 的计数；管理器加载时随机初始化内部时钟；移除未使用的关键字 `WORLD`、`PROGRAM`、`MOVE`；设置程序最大长度 |
| 4.21.0 | 智能提示（默认关闭）；修复字符串中的转义引号 |
| 4.22.0 | 修复 `SECOND`（单数）不乘 20 的问题；修复输入端 `RETAIN` 的多个问题；标签最大长度从 80 提高到 256 |
| 4.23.0 | 正则形式的资源标识符增加更多自动转小写规则 |
| 4.24.0 | 修复“秒”单位下偏移量不乘 20 的问题 |
| 4.25.0 | `EMPTY SLOTS IN` |
| 4.27.0 | 单数 `SLOT`；相对方向 `LEFT`/`RIGHT`/`FRONT`/`BACK`；管理器可以对自身进行输入输出；隧道式工厂管理器；修复 `FORGET` 的内存泄漏 |
| 4.29.0 | 修复输入槽位被重复收集；修复朝上、朝下的方块旋转相对方向时的问题；新增“槽位不支持抽取”警告；隧道式线缆、坚固线缆 |
| 4.33.0 | 支持 MC 26.1.2 |
| 4.34.0 | 本书依据的版本 |
| 4.35.0 | 无语言变化 |
