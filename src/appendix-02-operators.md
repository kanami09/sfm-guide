# 附录 B：运算符与符号

## 比较运算符

| 关键字 | 符号 | 含义 |
|---|---|---|
| `GT` | `>` | 大于 |
| `LT` | `<` | 小于 |
| `EQ` | `=` | 等于 |
| `GE` | `>=` | 大于等于 |
| `LE` | `<=` | 小于等于 |

没有“不等于”，用 `NOT x HAS EQ n` 代替。

## 布尔运算符（按优先级从高到低）

| 优先级 | 运算符 | 结合性 |
|---|---|---|
| 1（最高） | `( ... )` | — |
| 2 | `NOT` | 前缀 |
| 3 | `AND` | 左结合 |
| 4（最低） | `OR` | 左结合 |

`WITH` 子句中的 `NOT` / `AND` / `OR` / 括号遵循同样的优先级。

## 集合运算符（用于 HAS）

| 运算符 | 为真的条件 |
|---|---|
| `OVERALL`（默认） | 所有方块合计满足 |
| `EVERY` / `EACH` | 每个方块都满足 |
| `SOME` | 至少一个方块满足 |
| `ONE` | 恰好一个方块满足 |
| `LONE` | 至多一个方块满足 |

## 符号

| 符号 | 用途 | 示例 |
|---|---|---|
| `--` | 行注释 | `-- 注释` |
| `"..."` | 字符串：程序名、标签、正则资源 | `"storage a"` |
| `\"` | 字符串中的双引号 | `"say \"hi\""` |
| `,` | 列表分隔 | `FROM a, b` |
| `:` | 资源标识符和物品标签（tag）的分段 | `minecraft:stone` |
| `::` | 资源标识符简写：命名空间为任意 | `fluid::water` |
| `*` | 通配符（不加引号时） | `*ingot*` |
| `**` | 物品标签（tag）路径：匹配剩余的所有段 | `#essence/**` |
| `/` | 物品标签（tag）路径分隔 | `#c:ingots/iron` |
| `#` | 物品标签（tag）前缀 | `WITH #ores` |
| `-` | 槽位范围 | `SLOTS 0-8` |
| `+` | 定时偏移量（= `PLUS`） | `EVERY 20+5 TICKS` |
| `g` / `G` 后缀 | 全局时钟（= `GLOBAL`） | `EVERY 20G TICKS` |
| `( )` | 改变布尔表达式或 `WITH` 子句的结合顺序 | `(a OR b) AND c` |
