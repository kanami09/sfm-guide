# 编辑器与调试工具

## 内置文本编辑器

在管理器界面点击“编辑”（或按 `Ctrl + E`）即可打开。在标题界面和“选择世界”界面按 `Ctrl + E` 也能打开编辑器，方便你不进游戏就写好程序，然后复制出来。

| 按键 | 功能 |
| --- | --- |
| `Shift + Enter` | 保存并关闭 |
| `Tab` / `Shift + Tab` | 增加 / 减少缩进（4 个空格） |
| `Ctrl + /` | 注释或取消注释选中的行 |
| `Ctrl + Space` | 对光标所在的语法元素执行**上下文操作**（见下文） |
| 按住 `Ctrl` | 显示光标下语法元素的下划线提示 |
| `\`（反斜杠） | 接受智能提示（Intellisense）中选中的建议，按键可修改 |

编辑器左下角的按钮打开**编辑器配置**，可以设置：

- **行号显示**：默认关闭；
- **智能提示**：关闭（默认）/ 基础 / 高级；
- **首选编辑器**：V1（默认）/ V2。

### 上下文操作（Ctrl + Space）

把光标放在某个语法元素上再按 `Ctrl + Space`，SFM 会根据元素类型执行相应的检查（见 `ProgramTokenContextActions.java`）：

| 光标所在元素 | 操作 |
| --- | --- |
| 资源标识符（如 `*ingot*`） | 展开这个模式，列出它在当前游戏中**实际匹配到的所有资源 ID** |
| 标签 | 向服务器查询这个标签对应的方块 |
| `INPUT` 语句 | 检查这条输入语句，预览它能从哪些槽位取出什么 |
| `OUTPUT` 语句 | 检查这条输出语句 |
| 布尔表达式 / `IF` 语句 | 在服务器上计算条件，看当前结果 |

程序越复杂，这个功能越有用。拿不准 `*seed*` 到底会匹配哪些物品时，用它一查就知道。

## 示例程序

在管理器界面点击“**查看示例**”（`Ctrl + Shift + E`）打开**程序模板选择器**。里面的模板就是本书多次引用的 `template_programs/*.sfml`：

| 模板 | 内容 |
| --- | --- |
| A simple program | 最简单的输入输出 |
| Filtering | 按物品过滤、通配符、`EXCEPT` |
| Limits | 数量与 `RETAIN` 的各种组合 |
| Tag Matching | `WITH` / `WITHOUT` 物品标签（tag）匹配 |
| Slots and sides | 方向和槽位 |
| Empty Slots | `EMPTY SLOTS IN` |
| Forget | `FORGET` |
| Round Robin | `ROUND ROBIN` |
| IF statements | 条件与集合运算符 |
| Redstone signals / Redstone item movement | 红石相关 |
| Timer triggers | 定时触发器的全部写法 |
| Fluids and other resource types | 资源类型；最后一段是**根据当前游戏环境自动生成**的可用资源类型列表 |
| Furnace Manager / AE2 Inscribers | 实战示例 |
| Changelog / Known issues | 更新日志 / 已知问题 |

<div class="note">

**提示**：“Fluids and other resource types” 模板末尾的资源类型列表是在游戏运行时生成的，会反映你实际装了哪些模组、服务器禁用了哪些类型。想确认当前环境能用哪些资源类型，看这个模板最准确。

</div>

## 容器检查器（Ctrl + I）

打开任意容器的界面（比如箱子或熔炉），按 `Ctrl + I` 打开**容器检查器**。它会按方向（6 个面，加上“无方向”）逐个列出这个方块对每种资源类型暴露的**非空槽位**，每个槽位都写成一条现成的 SFML 输入语句，标签用 `target` 占位，形式大致如下：

```sfml
INPUT 3 iron_ore FROM target TOP SIDE SLOTS 0
```

照着这些语句就能确定“熔炉的燃料槽是几号”“机器哪个面能取出产物”。这是最可靠的办法。

<div class="warning">

**注意**：检查器显示的槽位编号**不一定**和自动化（物流）用的槽位编号一致，这一点检查器自己也会提示。SFML 的 `SLOTS` 用的是**物流能力（Capability）里的槽位编号**，而且不同的面可能暴露不同的槽位集合。

</div>

## 网络工具

- 手持时**透视显示**线缆；
- **右键方块的一个面**，在聊天栏输出诊断信息：这个面上存在哪些能力（物品、流体、能量……）等；
- 可以按键开关它的叠加层显示。

## 警告与错误

SFM 在编译程序时会做两类检查：

1. **语法错误**：程序无法解析，管理器状态显示“无效程序”。
2. **警告（lint）**：程序能运行，但看起来有问题。比如用到的标签在世界里不存在、某个 `INPUT` 后面没有 `OUTPUT` 来消费它、`EACH` 用在了没有通配符的资源上。

警告会标注在磁盘上（悬停可见），管理器界面也有一个警告按钮：

- **点击**：把带警告和错误注释的代码复制到剪贴板；
- **Shift + 点击**：尝试自动修复警告。

完整的警告列表和含义见[编译检查与警告](ch08-03-warnings.md)。

## 日志

管理器界面的“**查看日志**”打开日志窗口，可以调整日志级别。在调试级别下，你能看到每一刻执行了哪些语句、`IF` 条件是真是假、每个槽位搬了多少东西。“程序为什么没搬这个东西”这类问题，最终都可以靠日志查清楚。

管理器界面还会显示**峰值刻耗时**和**悬停刻耗时**（毫秒），用来判断程序有没有拖慢服务器。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `/sfm changelog` | 查看更新日志 |
| `/sfm config show` | 查看配置（所有人可用） |
| `/sfm config edit` | 编辑配置（需要管理员权限） |
| `/sfm bust_cable_network_cache` | 清空所有线缆网络缓存（管理器“莫名其妙”停止工作时可以试试） |
| `/sfm bust_water_network_cache` | 清空蓄水槽网络缓存 |
| `/sfm kit [player]` | 给予一套默认的 SFM 物品（管理员命令） |

管理器界面上的“**重建线缆网络**”按钮只重建当前这台管理器的网络。
