# 准备工作：方块与物品

运行 SFML 程序至少需要三样东西：**工厂管理器**、**程序磁盘**和**标签枪**。如果要连接远处的容器，还需要**线缆**。

> 下文名称以模组自带的简体中文语言文件（`zh_cn.json`）为准，括号里是英文名或注册名。合成配方请在游戏中用 JEI 查看。

## 核心三件套

### 工厂管理器（Factory Manager，`sfm:manager`）

程序在这个方块上运行。把程序磁盘放进它的界面，它就会按程序的逻辑搬运资源。

- 管理器本身也**相当于一段线缆**：直接贴着管理器的容器同样能被程序访问。
- 管理器界面上有这些按钮：编辑、从剪贴板粘贴、复制到剪贴板、查看示例、重置、重建线缆网络、查看日志、查看服务器配置。界面里还显示运行状态和每刻耗时。
- 状态有四种：**运行中**、**无程序**、**未插入磁盘**、**无效程序**（编译出错）。

### 工厂管理器程序磁盘（Disk，`sfm:disk`）

磁盘用来**保存程序源码和标签数据**。程序和标签都存在磁盘上，不存在管理器里，所以把磁盘拿出来插到另一台管理器上，程序和标签会一起过去。

- 鼠标悬停在磁盘上可以看到程序名、标签统计、警告和错误。
- 程序有长度上限（约 32,000 个字符），这是由 Minecraft 网络数据包的大小限制决定的。

### 标签枪（Label Gun，`sfm:labelgun`）

标签枪用来给世界中的方块**贴标签**。程序里不写坐标，只写标签名，比如 `INPUT FROM a` 的意思是“从所有贴了 `a` 标签的方块输入”。

常用操作（默认按键，可以在按键设置的“超级工厂管理器”分类里修改）：

| 操作 | 效果 |
| --- | --- |
| 右键方块 | 给方块贴上或撕下当前标签 |
| Shift + 滚轮 | 切换当前标签 |
| 右键空气 | 打开标签枪界面，可以输入或搜索标签 |
| 右键管理器 | **推送（push）**：把标签枪里记录的标签位置写入管理器中的磁盘 |
| Shift + 右键管理器 | **拉取（pull）**：从管理器的磁盘读取标签，包括程序里用到但还没贴的标签名 |
| Shift + 右键方块 | 清除该方块上的所有标签 |
| Ctrl + 右键方块 | 对与线缆相连的**连续同种方块**批量操作 |
| Alt + 右键方块 | 吸取该方块上的标签作为当前标签 |

<div class="warning">

**最常见的新手错误：贴完标签忘记推送。** 贴标签只修改标签枪自己的数据。只有拿着标签枪**右键管理器**，标签才会写进磁盘，程序才能看到。如果管理器提示 *"Did you remember to push your labels using the label gun?"*（你记得用标签枪推送标签了吗？），说的就是这件事。

</div>

<div class="note">

先在管理器里写好程序，再用标签枪 **Shift + 右键管理器**把程序里的标签名全部拉取到枪里，然后逐个标记到方块上，最后**右键管理器**推送，这样不用手动输入标签名，也不会拼错。仓库的 `examples/README.md` 也推荐这种做法。

</div>

## 线缆

容器必须通过线缆（或直接贴着管理器）**连进管理器的网络**，程序才能访问。没连上网络的方块就算贴了标签，程序也会忽略，并给出警告 *"Label ... is assigned in the world at ... but not connected by cables."*。

| 方块 | 说明 |
| --- | --- |
| 工厂线缆（`cable`） | 普通线缆，完整方块 |
| 精致工厂线缆（`fancy_cable`） | 模型不是完整方块的线缆 |
| 坚固工厂线缆（`tough_cable`） | 抗爆炸，可以伪装成更坚固的方块 |
| 隧道式工厂线缆（`tunnelled_cable`） | 把相邻方块的能力（Capability）**传递到另一侧** |
| 隧道式工厂管理器（`tunnelled_manager`） | 管理器版本的“隧道”，同样把能力传递到另一侧 |
| 各种“伪装板”（facade） | 线缆的伪装形态，让线缆看起来像别的方块 |

**线缆伪装**：主手拿想要伪装成的方块，副手拿网络工具，右键线缆。Ctrl + 右键连续伪装，Alt + 右键伪装网络中所有同种线缆，Ctrl + Alt + 右键伪装整个网络。

## 辅助工具

### 网络工具（Network Tool，`sfm:network_tool`）

- 拿在手上时可以**透视显示**线缆网络；
- **右键方块的某个面**显示诊断信息，比如这个面上有哪些能力（物品、流体、能量……）；
- 用来排查“为什么连不上”“这个面能不能抽出东西”之类的问题。

### 其他方块

| 方块 | 说明 |
| --- | --- |
| 蓄水槽（`water_tank`） | 无限水源。需要两个相邻的水源方块；和其他已激活的蓄水槽相邻时产水更多 |
| 印刷机（`printing_press`） | 放在朝下的活塞下方，中间隔一格空间，激活活塞即可使用；可以配合“印刷模板”复制物品，具体配方见 JEI |

这些方块与 SFML 语法关系不大，本书不展开介绍。
